# Projects

Agentic AI Resume Chatbot with RAG
- Built a production-ready agentic AI chatbot for my portfolio using Retrieval-Augmented Generation (RAG) with a React frontend and FastAPI backend.
- Implemented a complete RAG pipeline with ChromaDB vector search, SentenceTransformers embeddings, session-based memory, and GPT-4o-mini inference.
- Designed the system to stay resume-grounded, reduce hallucinations, and use deterministic fallback behavior.

Beyond Sight - Audible Graphs for the Visually Impaired
- Created and deployed an AI-powered accessibility system that converts Excel charts and image-based graphs into audio narratives for visually impaired users.
- Implemented and optimized ResNet-based deep learning models using TensorFlow and PyTorch, achieving 92% accuracy in chart classification and data extraction.
- Engineered an OCR + NLP pipeline with Pandas, NumPy, spaCy, and Tesseract to extract titles, axes, legends, and values with 85% precision.
- Integrated text-to-speech modules for real-time screen-reader-compatible audio feedback and presented the work at ACM W4A 2024.

Dynamic Pricing Prediction for Cabs
- ML models to predict cab pricing using supervised and reinforcement learning.

Accessible Weather and Shelter Finder
- Accessible web application for blind and visually impaired users.
- Provides real-time weather updates, severe weather alerts, and nearest shelter locations.
- Accessibility support includes keyboard navigation, high-contrast UI, shortcut keys, and text-to-speech.
